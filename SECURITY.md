# Security Policy

This project has no released versions with known vulnerabilities. Security
fixes are applied to the latest commit on `main`.

## Reporting a Vulnerability

Please open a private security advisory via GitHub's
["Report a vulnerability"](../../security/advisories/new) feature rather than
a public issue. Include:

- A description of the issue and its impact
- Steps to reproduce
- Any relevant logs or proof-of-concept code

Expect an initial response within a few days.
